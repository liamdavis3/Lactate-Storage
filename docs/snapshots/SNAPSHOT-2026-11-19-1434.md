## Completed this session
- `app.py` (single file, 4 sections: database, login, curve, screens):
  - SQLite with `users`, `workouts`, `tests` tables.
  - Login/register with salted SHA256 (`hashlib.pbkdf2_hmac`, 200k iterations, `os.urandom(16)` salt, `hmac.compare_digest`).
  - A workout holds 1+ tests (rep #, distance, pace as m:ss/mile, HR, lactate).
  - Curve fit `lactate = a + b*exp(c*HR)` via scipy; threshold = HR at 4 mmol/L.
  - Past-workouts table (one row per test) with "Delete selected workout" (deletes workout and its tests, scoped to user).
  - Curve screen has a "Color points by" dropdown: Date, RPE, Pace, Sleep, None.
- `requirements.txt` (pinned), `.gitignore` (`.venv/`, `__pycache__/`, `lactate.db`).
- Launchers outside the repo: `~/Desktop/Lactate.command` and `~/Applications/Lactate.app` (AppleScript applet with custom icon; user confirmed it works and plans to keep it in the Dock).
- All committed and pushed by the user; `lactate.db` was never committed.
